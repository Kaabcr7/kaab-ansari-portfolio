## Running the Portfolio Locally

No build step is required. Clone the repository and open `index.html` in a modern web browser:

```bash
git clone https://github.com/Kaabcr7/kaab-ansari-portfolio.git
cd kaab-ansari-portfolio
```

Then double-click `index.html`, or serve the directory with a local web server.
